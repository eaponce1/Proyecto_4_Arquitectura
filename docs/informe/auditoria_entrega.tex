\section*{Dictamen}

algoritmo y referencias (1,0), Assembly y métricas (0,8), co-diseño (1,2).

desde la maestra, resultados oficiales de tres rondas, defensa y cumplimiento
del plazo. Se contrasta con \path{docs/referencia/enunciado_proyecto4.pdf}.

\section*{Reproducción y comprobaciones}
El estudio final conserva 32 trazas comprimidas, hashes de fuentes, netlists,
logs y pruebas unitarias. \path{tools/auditar_codisenio_final.py} coteja todas
las filas contra precios originales y modelo causal, regiones y síntesis.
El estudio histórico de 60\,000 filas permanece separado.
Las pruebas unitarias incluyen reinicio lógico conservando BRAM y 1024
vectores de la instrucción personalizada. El BIN activo no se modifica.
El README incluye comandos y versiones. La auditoría PDF verifica autores,
secciones, firmas y ausencia de desbordes.
