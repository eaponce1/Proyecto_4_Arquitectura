# Datos, investigacion y pruebas de Proyecto 4

El codigo que se compila y programa esta en la raiz del proyecto: `../rtl/`, `../sw/`
y `../tools/`. Este directorio conserva las dependencias de investigacion y verificacion.

- `alternativas/competitiva_definitiva/`: estrategia congelada, ocho series, equivalencia y resultados.
- `alternativas/agresiva/`, `candidata_final/` y `mmio_sma10/`: fuentes de referencia usadas en comparaciones.
- `python/`: contabilidad, estrategias anteriores e interprete RV32E compartido por los validadores.
- `resultados/validacion_oficial/`: banco original del profesor y su CSV de referencia.
- `pruebas_fisicas/`: fuentes de referencia SPI y CPU trace utilizadas por los ejecutores.
- `data/`, `sw/`, `rtl/`, `tb/` y `tests/`: datos y fuentes de apoyo de Proyecto 4.

Las corridas obsoletas, demostraciones y builds duplicados se archivaron en el ZIP
verificado de `../../ARCHIVO_HISTORICO/`. Consultar `../README.md` para los comandos actuales.
